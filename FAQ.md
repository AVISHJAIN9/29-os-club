# Frequently Asked Questions: Gesture PDF Presenter & Web Annotator

### 1. What is Gesture PDF Presenter & Web Annotator?
Browser-based PDF slide presentation and annotation workspace supporting gesture interaction.

### 2. What technology stack does it use?
Built with React / TypeScript, PDF.js, Canvas API.

### 3. Where is this project deployed?
Hosted live at: https://avishjain9.github.io/29-os-club/

### 4. How can I run it locally?
Follow the installation and setup guide provided in [docs/SETUP.md](docs/SETUP.md) or the repository `README.md`.
