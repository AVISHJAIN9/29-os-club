# Human-Computer Interaction & Vision Glossary

- **MediaPipe**: Open-source cross-platform machine learning framework developed by Google for perceptual computing.
- **Landmark**: A normalized 3D spatial coordinate representing an anatomical joint (e.g. fingertip, wrist).
- **Refractory Period**: A temporary lockout duration following a gesture event preventing rapid accidental repeat triggers.
- **Device Pixel Ratio (DPR)**: The ratio between physical display pixels and logical CSS pixels.
